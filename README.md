# МК Онлайн

Адаптивный одностраничный сайт информационно-партнёрского сервиса «МК Онлайн».

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Сайт автоматически публикуется в GitHub Pages после отправки изменений в ветку `main`.

Формы работают только на уровне интерфейса и клиентской проверки. Передача заявок и внешние сервисы не подключены.
